# Как работать с возвратами

Возвраты маркетплейса загружаются в отдельное рабочее место и превращаются в документы возврата в 1С.

Возвраты входят в **хаб «Заказы»** — отдельной механики в мастере для них нет, они доступны при подключённой механике «Получение заказов FBS/FBO».

---

## Шаг 1. Открыть рабочее место возвратов

Рабочий стол проекта → строка **«Заказы»** → **▶ Рабочее место** → выделить любой заказ → кнопка **«↩ Возвраты»** в панели «Действия с заказом».

![Рабочее место возвратов](../images/returns-workplace.png)

---

## Шаг 2. Загрузить возвраты

| Элемент | Назначение |
|---|---|
| **Статус** | Фильтр по статусу возврата. По умолчанию `new` |
| **↺ Обновить** | Запросить возвраты с сервера |
| **📥 Создать возврат в 1С** | Создать документ возврата по выбранной строке |
| **Всего** | Счётчик загруженных возвратов |
| **Информация** | Диагностическое сообщение, например `Новых возвратов нет.` |

**Таблица:** ID возврата, отправление, статус, дата, количество товаров, ссылка на документ 1С.

Нажмите **«↺ Обновить»**. Если возвратов в выбранном статусе нет, в поле «Информация» появится `Новых возвратов нет.` — это штатный ответ, а не ошибка.

---

## Шаг 3. Создать документ возврата

1. Выделите строку возврата в таблице.
2. Нажмите **«📥 Создать возврат в 1С»**.
3. В колонке **«Документ 1С»** появится ссылка на созданный документ.

---

## Какие документы создаются

| Конфигурация | Документ возврата |
|---|---|
| **УТ 11** | Возврат товаров от клиента |
| **УНФ** | Возврат товаров от покупателя |
| **КА 2 / ERP** | Возврат товаров от покупателя (организация обязательна) |
| **БП 3.0** | ⚠️ Поддерживается ограниченно |

---

## Частые проблемы

| Симптом | Решение |
|---|---|
| «Новых возвратов нет» при наличии возвратов на площадке | Смените значение фильтра **«Статус»** — по умолчанию показываются только `new` — и нажмите **«↺ Обновить»** |
| Кнопка «↩ Возвраты» неактивна | Не выделен заказ в таблице рабочего места «Заказы» |
| Документ возврата не создаётся | Проверьте реквизиты Шага 4 мастера (контрагент, склад); в КА 2 / ERP — организацию. Товар возврата должен быть сопоставлен с номенклатурой 1С |
| Таблица пустая после «Обновить» | Проверьте статус проекта (`Активен`) и что возвраты действительно есть в кабинете площадки |
