# Как настроить синхронизацию цен

Механика отправляет цены из 1С на маркетплейс или сайт. По умолчанию выгрузка идёт **раз в сутки в 03:00**.

---

## Шаг 1. Открыть настройку

Рабочий стол проекта → строка **«Цены»** → **⚙ Настройка**.

![Настройка синхронизации цен](../images/prices-setup.png)

---

## Шаг 2. Указать тип цены (обязательно)

Блок **«Типы цен»**:

| Поле | Назначение |
|---|---|
| **ТипЦены** | Основной тип цен, который уходит на площадку |
| **ТипМинЦены** | Тип минимальной цены (нижняя граница, если площадка её поддерживает) |

Кнопка **«↺ Обновить список типов цен из базы»** перечитывает справочник типов цен вашей конфигурации.

Кнопка **«Предпросмотр: какие цены уйдут на маркетплейс сейчас ↗»** показывает результат до отправки — пользуйтесь ей перед первым запуском.

**Таблица кабинетов** ниже показывает, какой тип цены и какая минимальная цена заданы для каждого проекта.

> Без указанного типа цены выгрузка не работает — это самая частая причина «цены не уходят».

---

## Шаг 3. Расписание и округление

Блок **«Расписание и округление»**:

| Параметр | Что задаёт |
|---|---|
| **ВремяВыгрузки** | Время суток для плановой выгрузки. По умолчанию `03:00` |
| **Пн … Вс** | Дни недели, в которые выполняется выгрузка. По умолчанию — рабочие дни |
| **Выгружать цены после изменения в 1С (опционально)** | Дополнительно отправлять цену сразу при её изменении, не дожидаясь расписания |

---

## Шаг 4. Корректировки и предпросмотр

Блок **«Корректировки»** — правила изменения цены при выгрузке в разрезе кабинета (например наценка или скидка для конкретной площадки).

Блок **«Предпросмотр»** — поля **ПредпросмотрЦены**, **ПредпросмотрИтог**, **ПредпросмотрОписание**: позволяют увидеть, во что превратится цена после применения корректировок.

Нажмите **«Сохранить»**.

---

## Шаг 5. Проверить выгрузку

Рабочий стол → строка **«Цены»** → **▶ Рабочее место**.

Открывается общий экран хаба «Товары» — **«Управление товарами 1С»**.

![Управление товарами 1С](../images/goods1c-sync.png)

Кнопка **«Синхронизировать цены ↑»** отправляет цены немедленно.

В таблице сравните колонки **«Цена 1С»**, **«Цена МП»** и **«Δ цена»**. Ненулевая дельта означает расхождение — нажмите синхронизацию.

---

## Как это работает

1. По расписанию модуль читает цену указанного типа по каждой позиции.
2. Применяет корректировки, если они заданы для кабинета.
3. Отправляет цены **только по сопоставленным товарам**.

Несопоставленный товар в выгрузку не попадает.

---

## Различия по конфигурациям 1С

| Конфигурация | Как называется справочник цен |
|---|---|
| **УТ 11** | Типы цен номенклатуры |
| **УНФ** | Типы цен |
| **КА 2 / ERP** | ⚠️ **Виды цен** (прайс-листы) — другое название того же понятия |
| **БП 3.0** | Типы цен номенклатуры |

В любом случае список подгружается кнопкой **«↺ Обновить список типов цен из базы»** — выбирайте из того, что реально есть в вашей базе.

В КА 2 / ERP цены дополнительно фильтруются по организации проекта.

## Частые проблемы

| Симптом | Решение |
|---|---|
| Цены не уходят | Не указан **ТипЦены**. Откройте настройку, выберите тип, сохраните |
| Список типов цен пустой | Нажмите **«↺ Обновить список типов цен из базы»** |
| Нужного типа цен нет в списке | В КА 2 / ERP это «виды цен» — проверьте, что вид цены заведён в базе и по нему есть значения |
| Цена ушла не та, что ожидалась | Проверьте блок «Корректировки» и воспользуйтесь **«Предпросмотр…»** |
| Δ цена не обнуляется после синхронизации | Товар не сопоставлен, либо площадка отклонила цену (например ниже минимальной) |
| Цены выгружаются слишком редко | Измените **ВремяВыгрузки**/дни недели или включите «Выгружать цены после изменения в 1С» |
| Цена изменилась в 1С, а на площадке старая | Плановая выгрузка идёт раз в сутки. Нажмите **«Синхронизировать цены ↑»** вручную либо включите выгрузку по изменению |
