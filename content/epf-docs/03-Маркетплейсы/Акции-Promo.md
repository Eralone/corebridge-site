# Как подключить товары к акциям (только Ozon)

Механика позволяет посмотреть акции кабинета Ozon, увидеть товары-кандидаты с рекомендованной ценой и подключить выбранные позиции к акции — не выходя из 1С.

**Доступна только для Ozon.** Механика **не создаёт документов 1С** и не обращается к Ozon напрямую — всё идёт через сервер платформы.

---

## Шаг 1. Включить механику

**Шаг 3В** мастера → отметить **«Участие в акциях / Promo (только Ozon)»**.

![Шаг 3В: механики Ozon](../images/master-step3v-mech-ozon.png)

В существующем проекте: рабочий стол → **«Механики (Шаг 3В)»**.

---

## Шаг 2. Настройка

Рабочий стол проекта → строка **«Акции / Promo»** → **⚙ Настройка**.

![Настройка акций](../images/promo-setup.png)

Настройка минимальна — механика работает в ручном режиме, основное происходит в рабочем месте.

---

## Шаг 3. Рабочее место «Акции»

Рабочий стол → строка **«Акции / Promo»** → **▶ Рабочее место**.

![Рабочее место акций](../images/promo-workplace.png)

При открытии таблица пуста, а в поле **«ТекстИнфо»** написано: **«Нажмите "↺ Обновить акции" для загрузки списка»**.

Это сделано намеренно: форма не делает сетевой запрос при открытии, чтобы не подвешивать сеанс. Загрузка запускается кнопкой.

### Верхняя таблица — акции

| Элемент | Назначение |
|---|---|
| **Кабинет** | Проект |
| **Обновлено** | Время последней загрузки |
| **↺ Обновить акции** | Загрузить список акций кабинета |
| **ТекстИнфо** | Подсказка и статус |

**Колонки:** ID акции, название, тип, начало, окончание, количество товаров.

### Нижняя таблица — товары-кандидаты

| Кнопка | Действие |
|---|---|
| **📋 Кандидаты выбранной акции** | Загрузить товары, которые можно подключить к выделенной акции |
| **✅ Подключить отмеченные товары** | Отправить выбранные позиции на подключение |

**Колонки:** отметка, артикул Ozon, `product_id`, текущая цена, цена 1С, акционная цена, максимальная акционная цена.

Колонка **«Цена 1С»** показывает вашу цену рядом с акционной — по ней сразу видно, насколько глубока скидка и не уходите ли вы в минус.

---

## Типовой сценарий

1. Открыть рабочее место → **«↺ Обновить акции»**.
2. Выделить нужную акцию в верхней таблице.
3. Нажать **«📋 Кандидаты выбранной акции»** — загрузятся товары с рекомендованными ценами.
4. Сравнить **«Цена 1С»** и **«Акц. цена»**, отметить подходящие позиции.
5. Нажать **«✅ Подключить отмеченные товары»**.
6. Результат подключения приходит с сервера асинхронно — обновите таблицу через некоторое время.

---

## Частые проблемы

| Симптом | Решение |
|---|---|
| Механики нет на Шаге 3В | Акции доступны только для Ozon. Проверьте сервис проекта |
| Таблица акций пустая, в «ТекстИнфо» — подсказка | Это штатное состояние при открытии. Нажмите **«↺ Обновить акции»** |
| После «Обновить акции» список пуст | В кабинете Ozon нет активных акций, доступных продавцу |
| Кандидаты не загружаются | Не выделена акция в верхней таблице |
| Результат подключения не виден | Он приходит асинхронно. Подождите и нажмите **«↺ Обновить акции»** |
| «Цена 1С» пустая | Товар не сопоставлен с номенклатурой 1С. См. [Каталог и сопоставление](Каталог-и-сопоставление.md) |
