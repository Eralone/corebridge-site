# Как подключить Wildberries

Wildberries поддерживает **8 механик**. Три механики Ozon (резервы, ГТД, акции/Promo) для WB недоступны — соответствующие чекбоксы в мастере не показываются.

**Время на подключение:** 10–15 минут.

---

## Шаг 1. Запустить мастер

Каталог проектов → **«+ Добавить интеграцию»**. Шаги 1–2 — см. **[Мастер подключения](../02-Основы/Мастер-подключения.md)**.

---

## Шаг 2. Категория и сервис

**Шаг 3А** → категория **`marketplace` (Маркетплейсы)**.
**Шаг 3Б** → сервис **`wb`**.

Схемы работы:

| Схема | Когда выбирать |
|---|---|
| **FBS** | Товар на вашем складе, вы собираете и отгружаете заказы |
| **FBO/FBM** | Товар на складе Wildberries (поставки FBW) |

Схемы взаимоисключающие по составу механик — при необходимости создайте два проекта.

---

## Шаг 3. Механики

![Шаг 3В: механики Wildberries](../images/master-step3v-mech-wb.png)

| Механика | Что делает | Инструкция |
|---|---|---|
| Получение заказов FBS/FBO | Забирает заказы WB, создаёт документы в 1С | [Заказы и отгрузка](Заказы-и-отгрузка.md) |
| Подтверждение отгрузки | Документ отгрузки + уведомление WB | [Заказы и отгрузка](Заказы-и-отгрузка.md) |
| Выгрузка остатков | Отправляет остатки складов на WB | [Остатки](Остатки.md) |
| Синхронизация цен | Отправляет цены из 1С на WB | [Цены](Цены.md) |
| Финансовые отчёты МП | Загружает отчёты и отражает в 1С | [Финансовые отчёты](Финансовые-отчёты.md) |
| Маркировка «Честный знак» | Передаёт коды маркировки | [Маркировка](Маркировка-Честный-знак.md) |
| Управление каталогом товаров | Сопоставление товаров 1С ↔ WB | [Каталог и сопоставление](Каталог-и-сопоставление.md) |
| Печать этикеток | Этикетки заказов и грузовых мест | [Этикетки](Этикетки.md) |

### Чего у Wildberries нет

| Механика | Причина |
|---|---|
| Резервирование запасов | Только Ozon |
| Передача ГТД | Только Ozon |
| Участие в акциях / Promo | Только Ozon |

Это не ограничение модуля — соответствующих сценариев нет в API Wildberries.

---

## Шаг 4–6. API, реквизиты, запуск

Ничем не отличаются от Ozon:

- **Шаг 3Г** — оставьте **★ Рекомендуемые**, частота `15min`.
- **Шаг 4** — название («WB Розница»), контрагент, склад отгрузки, договор; организация обязательна только в КА 2 / ERP.
- **Шаг 5** — **«✓ Завершить и запустить»**.

Подробности с иллюстрациями — в разделах «Шаг 4–6» инструкции [Как подключить Ozon](Подключить-Ozon.md).

---

## Шаг 7. Настроить после создания

1. **Склады для остатков** — строка «Остатки» → **⚙ Настройка** → **✓ Выбрать все** → **Сохранить**.
2. **Сопоставить товары** — строка «Каталог» → **▶ Рабочее место** → **«Загрузить товары ↓»** → **«⚡ Автосопоставить»**.
3. **Тип цен** — строка «Цены» → **⚙ Настройка** → выбрать тип цены → **Сохранить**.
4. **Статусы заказов** — строка «Заказы» → **⚙ Настройка** → отметить забираемые статусы.

---

## Особенности Wildberries

| Особенность | Комментарий |
|---|---|
| **Статусы заказов** | WB использует собственную пару статусов (статус поставщика и статус WB). Модуль приводит их к единому виду в рабочем месте заказов |
| **Поставки FBW** | Работа с поставками на склад WB — в хабе «Заказы» и в механике поставок при схеме FBO/FBM |
| **Колонки ГТД / Страна / РНПТ** | В рабочем месте заказов не заполняются — эти данные WB не передаёт |

---

## Частые проблемы

| Симптом | Решение |
|---|---|
| Нет чекбоксов резервов / ГТД / акций | Ожидаемо: они только для Ozon |
| Заказы не приходят | Статус проекта `Активен`; в настройке заказов отмечены нужные статусы; «▶ Запустить цикл сейчас» |
| Остатки не уходят | Не выбраны склады либо товары не сопоставлены |
| Цены не уходят | Не указан тип цен |
