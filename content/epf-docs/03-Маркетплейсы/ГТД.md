# Как настроить передачу ГТД (только Ozon)

Механика передаёт номера таможенных деклараций (ГТД) по импортным товарам в заказы Ozon.

**Доступна только для Ozon.** Как и маркировка, механика **хуковая** — собственного расписания у неё нет, она срабатывает при обработке заказа.

---

## Шаг 1. Включить механику

**Шаг 3В** мастера → отметить **«Передача ГТД (только Ozon)»**.

![Шаг 3В: механики Ozon](../images/master-step3v-mech-ozon.png)

В существующем проекте: рабочий стол → **«Механики (Шаг 3В)»** → отметить → пройти мастер до конца.

---

## Шаг 2. Настроить

Рабочий стол → строка **«ГТД»** → **⚙ Настройка**.

![Настройка ГТД](../images/gtd-setup.png)

| Поле / кнопка | Назначение |
|---|---|
| **НазваниеКабинета** | Выбор кабинета Ozon из выпадающего списка. Если активных кабинетов нет, показывается `Нет активных кабинетов Ozon` |
| **Отключить отправку ГТД для Ozon** | Временно приостановить передачу, не отключая механику |
| **Текущий режим** | Текущее состояние передачи |
| **Статус** | Результат последней операции |
| **Рабочее место FBS ↗** | Переход в рабочее место заказов |

Нажмите **«Сохранить»**.

> Если в поле кабинета написано `Нет активных кабинетов Ozon` — значит в проекте нет активной интеграции Ozon. Проверьте статус проекта в каталоге.

---

## Шаг 3. Заполнить ГТД по заказу

Рабочий стол → **«Заказы»** → **▶ Рабочее место**.

![Рабочее место заказов: колонки ГТД, Страна, РНПТ](../images/orders-workplace.png)

В таблице заказов три связанные колонки:

| Колонка | Значение |
|---|---|
| **ГТД** | Номер таможенной декларации |
| **Страна** | Страна происхождения товара |
| **РНПТ** | Регистрационный номер партии товара |

Если по заказу требуются эти данные, в колонках отображается **`⚠ требуется`**.

Чтобы заполнить: выделите заказ → кнопка **«📄 Указать ГТД»** в панели «Действия с заказом».

![Панель действий с заказом](../images/shipment-workplace.png)

---

## Как это работает

1. Механика заказов получает заказ с Ozon.
2. Если товар импортный и требует таможенных данных, в колонках ГТД / Страна / РНПТ появляется `⚠ требуется`.
3. Вы заполняете данные кнопкой «Указать ГТД».
4. Модуль передаёт номер декларации на Ozon и сохраняет его в 1С.

---

## Различия по конфигурациям 1С

| Конфигурация | Учёт ГТД |
|---|---|
| **УТ 11** | Реквизит документа, заполняется вручную через модуль |
| **УНФ** | Реквизит документа, заполняется вручную через модуль |
| **КА 2 / ERP** | Встроенный учёт таможенных деклараций — данные берутся из учётной системы |
| **БП 3.0** | ⚠️ Ограниченная поддержка |

## Частые проблемы

| Симптом | Решение |
|---|---|
| Механики нет на Шаге 3В | ГТД доступна только для Ozon. Проверьте сервис проекта |
| `Нет активных кабинетов Ozon` в настройке | Проект не активен или не является Ozon-проектом. Проверьте статус в каталоге проектов |
| Кнопка «Указать ГТД» неактивна | Механика ГТД не подключена к проекту, либо не выделен заказ |
| Колонки ГТД / Страна / РНПТ пустые у всех заказов | По этим заказам таможенные данные не требуются — это нормально для товаров российского производства |
| Данные заполнили, но `⚠ требуется` остаётся | Нажмите **«↺ Обновить заказы»** |
| Передачу нужно временно остановить | Настройка → флажок **«Отключить отправку ГТД для Ozon»** → **Сохранить** |
