# Как настроить поставки FBM / FBO

Механика ведёт поставки товара на склад маркетплейса: формирование поставки, упаковка по грузовым местам, отгрузка.

**Механика доступна только при схеме работы FBO/FBM.** При схеме FBS она скрыта в мастере — это не ошибка, а разделение сценариев.

---

## Шаг 1. Создать проект со схемой FBO/FBM

В мастере на **Шаге 3Б** отметьте схему **«FBO/FBM — товар на складе маркетплейса (поставки)»**.

![Шаг 3Б: схемы работы](../images/master-step3b-service-ozon.png)

> Схемы FBS и FBO/FBM взаимоисключающие по составу механик. Если вы уже работаете по FBS и хотите добавить поставки — **создайте второй проект** на тот же кабинет, выбрав схему FBO/FBM.

На **Шаге 3В** появится чекбокс механики поставок.

---

## Шаг 2. Настроить механику

Рабочий стол проекта → строка **«FBM»** → **⚙ Настройка**.

![Настройка FBM](../images/fbm-setup.png)

Здесь задаются параметры формирования поставок: склад-источник, режим создания документов, правила упаковки. Состав полей зависит от площадки и конфигурации 1С.

Нажмите **«Сохранить»**.

---

## Шаг 3. Рабочее место поставок

Рабочий стол → строка **«FBM»** → **▶ Рабочее место**.

![Управление поставками FBM](../images/fbm-workplace.png)

### Фильтр

Поле **«Кабинет»** и кнопки-фильтры по стадиям:

| Фильтр | Что показывает |
|---|---|
| **Все** | Все поставки |
| **Новые** | Только что созданные |
| **Упаковать** | Готовые к упаковке |
| **К отгрузке** | Упакованные, ожидающие отгрузки |
| **Архив** | Завершённые |

### Таблица поставок

ID поставки, склад маркетплейса, дата, статус, количество мест, ссылка на документ 1С.

### Кнопки

| Кнопка | Действие |
|---|---|
| **+ Новая поставка** | Создать поставку |
| **Открыть** | Открыть выбранную поставку |
| **Упаковка →** | Перейти к упаковке по грузовым местам |
| **✓ Отгрузить** | Подтвердить отгрузку поставки |
| **↺ Обновить** | Перечитать список |
| **Упаковка поставки** | Открыть экран упаковки |

---

## Типовой цикл работы

1. **+ Новая поставка** — создать поставку, выбрать склад маркетплейса и товары.
2. **Упаковка →** — распределить товар по грузовым местам (коробам, паллетам).
3. Напечатать этикетки грузовых мест — см. [Этикетки](Этикетки.md).
4. **✓ Отгрузить** — подтвердить отгрузку; модуль сообщает площадке и создаёт документ отгрузки в 1С.
5. Поставка уходит в фильтр **«Архив»**.

## Различия по конфигурациям 1С

| Конфигурация | Особенности |
|---|---|
| **УТ 11** | Полная поддержка, включая **ордерную схему склада** (расходный ордер) |
| **УНФ** | Поддерживается. Ордерная схема — нет |
| **КА 2 / ERP** | Поддерживается, организация обязательна. Ордерная схема — нет |
| **БП 3.0** | Поддерживается ограниченно — складского учёта в полном объёме нет |

Ордерная схема включается флажком **«На складе включена ордерная схема»** в [настройке отгрузки](Заказы-и-отгрузка.md).

## Частые проблемы

| Симптом | Решение |
|---|---|
| Механики нет на Шаге 3В | Выбрана схема FBS. Вернитесь на Шаг 3Б и отметьте FBO/FBM, либо создайте отдельный проект |
| Таблица поставок пустая | Нажмите **«↺ Обновить»**; проверьте фильтр (по умолчанию может стоять не «Все»); убедитесь, что поставки созданы |
| Не создаётся поставка | Проверьте реквизиты Шага 4 мастера: склад отгрузки, контрагент; в КА 2 / ERP — организацию |
| Товар не попадает в поставку | Товар не сопоставлен. См. [Каталог и сопоставление](Каталог-и-сопоставление.md) |
| Не печатаются этикетки грузовых мест | Механика этикеток не подключена либо не настроен принтер. См. [Этикетки](Этикетки.md) |
| Нужны обе схемы (FBS и FBO) | Создайте два проекта на один кабинет |
