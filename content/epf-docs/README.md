# CoreBridge EPF — инструкции пользователя

Документация по установке и настройке модуля CoreBridge EPF для 1С.

**Начните отсюда:**

1. Установите модуль — выберите инструкцию под свою конфигурацию 1С в разделе [Установка](#1-установка).
2. Прочитайте [Мастер подключения](02-Основы/Мастер-подключения.md) — это общий сценарий для всех интеграций.
3. Откройте инструкцию под вашу задачу в разделах [3–7](#3-маркетплейсы).

---

## Быстрое решение частых проблем

| Симптом | Где искать |
|---|---|
| Не проходит подключение на Шаге 1 | [Мастер подключения → что делать, если что-то пошло не так](02-Основы/Мастер-подключения.md#что-делать-если-что-то-пошло-не-так) |
| Проект создан, но данных нет | [Каталог проектов и рабочий стол → типовые вопросы](02-Основы/Каталог-проектов-и-рабочий-стол.md#типовые-вопросы) |
| Остатки или цены не выгружаются | [Остатки](03-Маркетплейсы/Остатки.md), [Каталог и сопоставление](03-Маркетплейсы/Каталог-и-сопоставление.md) |
| Заказы не приходят | [Заказы и отгрузка](03-Маркетплейсы/Заказы-и-отгрузка.md#частые-проблемы) |
| Нужной механики нет в мастере | Проверьте сервис и схему работы на Шаге 3Б — часть механик площадко-специфична |
| Таблица на форме не обновляется | Нажмите кнопку **«Обновить»** на самой форме — формы 1С не перечитывают данные при переключении вкладок |

## О скриншотах

Все изображения — реальные экраны модуля в веб-клиенте 1С, снятые при автоматизированном тестировании сборки на демонстрационной базе **1С:Управление торговлей 11**.

В других конфигурациях расположение элементов такое же; отличаются только состав полей и доступность отдельных механик — это отмечено в разделах «Различия по конфигурациям 1С» каждой инструкции.
