# Установка CoreBridge EPF — 1С:Управление нашей фирмой

| Параметр | Значение |
|---|---|
| Файл модуля | `unified_unf.epf` |
| Конфигурация | 1С:Управление нашей фирмой (УНФ) |
| Сервер платформы | `https://api.corebridge.ru` |
| Платформа 1С | 8.3.14 и выше (рекомендуется 8.3.22+) |
| Режим работы | Управляемое приложение: тонкий, толстый или веб-клиент |
| Сетевые требования | Только исходящий HTTPS на `api.corebridge.ru:443` |
| Прямые вызовы API маркетплейсов | Нет — весь обмен идёт через сервер платформы |

CoreBridge EPF — единая внешняя обработка. Один файл содержит все механики платформы; нужные включаются в мастере при создании проекта.

---

## 1. Что нужно до начала

1. Аккаунт на **corebridge.ru** с активной лицензией.
2. **JWT-токен** из Личного кабинета.
3. Права администратора в 1С (для установки через «Дополнительные отчёты и обработки»).
4. Открытый исходящий HTTPS до `api.corebridge.ru:443`.

> Модуль не открывает входящих портов. На сервер уходят только JSON-события по настроенным механикам.

---

## 2. Получение файла

1. Личный кабинет на **corebridge.ru** → **«Файл .epf и JWT-токен»**.
2. Конфигурация — **1С:УНФ**.
3. Скопируйте **JWT-токен**.
4. Скачайте **`unified_unf.epf`**.

---

## 3. Установка

### Вариант А — через «Дополнительные отчёты и обработки» (рекомендуется)

1. **Компания** → **Администрирование** → **Печатные формы, отчёты и обработки** → **Дополнительные отчёты и обработки**.
2. **Добавить из файла…** → **Продолжить** → `unified_unf.epf`.
3. Укажите раздел размещения (например **Продажи**).
4. **Записать и закрыть**.

### Вариант Б — открыть файл напрямую

**Файл** → **Открыть** → `unified_unf.epf`. Подходит для разовой проверки.

---

## 4. Первый запуск

Откроется вкладка **CoreBridge. Каталог проектов** → **«+ Добавить интеграцию»**.

Полный разбор шагов — **[Мастер подключения](../02-Основы/Мастер-подключения.md)**.

| Шаг | Что делаете |
|---|---|
| 1. Подключение | URL + JWT → **Проверить подключение** |
| 2. Конфигурация 1С | Определяется автоматически как `unf` |
| 3А–3Г | Категория → сервис и схема → механики → API и частота |
| 4. Реквизиты | Название, контрагент, склад, договор |
| 5. Запуск | **✓ Завершить и запустить** |

---

## 5. Особенности УНФ

| Что | Как в УНФ |
|---|---|
| **Организация в документах** | Не обязательна |
| **Склады** | Полноценный складской учёт, доступен выбор нескольких складов |
| **Заказы** | Создаётся документ заказа клиента |
| **Отгрузка** | Создаётся расходная накладная |
| **Оплата** | Кассовые ордера (приходный / расходный) |
| **Резервирование** | Поддерживается через регистр резервов запасов |
| **Маркировка «Честный знак»** | Поддерживается; структура табличной части кодов маркировки отличается от УТ 11 — заполняется автоматически |
| **Финансовые отчёты МП** | Базовая схема отражения (отчёт комиссионера). Расширенные схемы недоступны |
| **FBM/FBO** | Поддерживается. Ордерная схема склада — **не поддерживается** |
| **Справочник партнёров** | Отсутствует, работа ведётся напрямую с контрагентами |
| **Типы цен** | Список подгружается кнопкой на форме настройки цен |

---

## 6. Автообновление модуля

Раз в сутки модуль проверяет наличие новой версии `unified_unf.epf` на сервере платформы. При наличии обновления предлагает обновиться прямо из интерфейса 1С.

---

## 7. Диагностика

| Симптом | Что проверить |
|---|---|
| На Шаге 1 статус подключения пустой | Доступность `api.corebridge.ru:443`, прокси/файрвол, срок действия JWT |
| Проект создан, но данных нет | Статус проекта = `Активен`; нажать **«▶ Запустить цикл сейчас»** |
| Пустая таблица в рабочем месте | Нажать **«Обновить»** на самой форме |
| Остатки не выгружаются | В **⚙ Настройка** механики «Остатки» не выбраны склады → **✓ Выбрать все** → **Сохранить** |
| Товары не синхронизируются | Не выполнено сопоставление номенклатуры — см. [Каталог и сопоставление](../03-Маркетплейсы/Каталог-и-сопоставление.md) |
| Нет расширенных схем финансового отчёта | Ожидаемо: в УНФ доступна только базовая схема |
| Не работает ордерная схема FBM | Ожидаемо: ордерная схема доступна только в УТ 11 |
