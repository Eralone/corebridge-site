# Установка CoreBridge EPF — 1С:Комплексная автоматизация 2 / ERP

| Параметр | Значение |
|---|---|
| Файл модуля | `unified_ka.epf` |
| Конфигурация | 1С:Комплексная автоматизация 2 / 1С:ERP |
| Сервер платформы | `https://api.corebridge.ru` |
| Платформа 1С | 8.3.14 и выше (рекомендуется 8.3.22+) |
| Режим работы | Управляемое приложение: тонкий, толстый или веб-клиент |
| Сетевые требования | Только исходящий HTTPS на `api.corebridge.ru:443` |
| Прямые вызовы API маркетплейсов | Нет — весь обмен идёт через сервер платформы |

CoreBridge EPF — единая внешняя обработка со всеми механиками платформы. Нужные включаются в мастере при создании проекта.

---

## 1. Что нужно до начала

1. Аккаунт на **corebridge.ru** с активной лицензией.
2. **JWT-токен** из Личного кабинета.
3. Права администратора в 1С.
4. Открытый исходящий HTTPS до `api.corebridge.ru:443`.
5. **Заранее определитесь, от какой организации будут создаваться документы** — в КА 2 / ERP это обязательный реквизит (см. §5).

---

## 2. Получение файла

1. Личный кабинет на **corebridge.ru** → **«Файл .epf и JWT-токен»**.
2. Конфигурация — **1С:КА 2 / ERP**.
3. Скопируйте **JWT-токен**.
4. Скачайте **`unified_ka.epf`**.

---

## 3. Установка

### Вариант А — через «Дополнительные отчёты и обработки» (рекомендуется)

1. **НСИ и администрирование** → **Печатные формы, отчёты и обработки** → **Дополнительные отчёты и обработки**.
2. **Добавить из файла…** → **Продолжить** → `unified_ka.epf`.
3. Укажите раздел размещения (например **Продажи**).
4. **Записать и закрыть**.

### Вариант Б — открыть файл напрямую

**Файл** → **Открыть** → `unified_ka.epf`.

---

## 4. Первый запуск

Откроется вкладка **CoreBridge. Каталог проектов** → **«+ Добавить интеграцию»**.

Полный разбор шагов — **[Мастер подключения](../02-Основы/Мастер-подключения.md)**.

> ⚠️ **На Шаге 4 обязательно заполните поле «Организация».** Без неё документы в КА 2 / ERP создаваться не будут.

---

## 5. Особенности КА 2 / ERP

Конфигурация поддерживает полный набор механик, но имеет два системных отличия от УТ 11 и УНФ.

### 5.1. Организация обязательна везде

Поле **«Организация»** на Шаге 4 мастера — обязательное. Оно подставляется во все создаваемые документы: заказы, реализации, кассовые ордера, возвраты, документы взаиморасчётов.

Кроме того, по организации фильтруются данные при чтении:

- остатки товаров;
- цены;
- продажи для аналитических выгрузок.

Это значит, что **проект работает в разрезе одной организации**. Если нужно вести несколько организаций — создайте отдельный проект на каждую.

### 5.2. Партнёры и контрагенты

В КА 2 / ERP используется связка **Партнёр + Контрагент**. Модуль создаёт и находит обе сущности:

- при создании контрагента из данных заказа или CRM дополнительно создаётся партнёр;
- при поиске получателя доставки данные берутся из партнёра;
- при синхронизации контактов CDP выгружаются партнёры (а не контрагенты напрямую).

### 5.3. Прочие отличия

| Что | Как в КА 2 / ERP |
|---|---|
| **Склады** | Полноценный складской учёт, фильтрация по организации |
| **Заказы** | Создаётся документ заказа клиента с обязательной организацией |
| **Отгрузка** | Создаётся реализация товаров и услуг |
| **Оплата** | Кассовые ордера (приходный / расходный) с обязательной организацией |
| **Резервирование** | Поддерживается через регистр запасов компании |
| **Маркировка «Честный знак»** | Поддерживается по расширенной схеме |
| **Финансовые отчёты МП** | Базовая и расширенные схемы + поддержка ЕАЭС |
| **Учёт ГТД** | Встроенный учёт таможенных деклараций |
| **Типы цен** | В КА 2 / ERP используются **виды цен** (прайс-листы) — список подгружается кнопкой на форме настройки цен |
| **FBM/FBO** | Поддерживается. Ордерная схема склада — не поддерживается |

---

## 6. Автообновление модуля

Раз в сутки модуль проверяет наличие новой версии `unified_ka.epf` на сервере платформы и предлагает обновиться из интерфейса 1С.

---

## 7. Диагностика

| Симптом | Что проверить |
|---|---|
| Документы не создаются, в журнале ошибка по реквизитам | Не заполнена **Организация** на Шаге 4. Рабочий стол → **Реквизиты (Шаг 4)** → указать организацию → сохранить |
| Остатки пустые при заполненных складах | Проверьте, что выбранные склады относятся к организации проекта |
| Не находится контрагент из CRM/заказа | В КА 2 поиск идёт через партнёра. Проверьте, что у контрагента есть связанный партнёр |
| На Шаге 1 статус подключения пустой | Доступность `api.corebridge.ru:443`, прокси/файрвол, срок действия JWT |
| Пустая таблица в рабочем месте | Нажать **«Обновить»** на самой форме |
| Не найден нужный тип цен | В КА 2 / ERP это «виды цен». Нажмите **«↺ Обновить список типов цен из базы»** в настройке цен |
