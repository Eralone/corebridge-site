Механика синхронизирует резервы Ozon с 1С: маркетплейс сообщает, сколько единиц зарезервировано под заказы, а модуль отражает это в учёте, чтобы зарезервированный товар не уходил в остатки повторно.

Доступна только для Ozon. У Wildberries и Яндекс.Маркета соответствующего API нет — чекбокс в мастере не показывается.

Не поддерживается в БП 3.0.

Шаг 1. Включить механику

При создании проекта

Мастер, Шаг 3В → отметьте «Резервирование запасов (только Ozon)».

В существующем проекте

Рабочий стол проекта → «Механики (Шаг 3В)» → отметить резервы → пройти мастер → «✓ Завершить и запустить».

Шаг 2. Включить передачу резервов в кабинете Ozon

⚠️ Это обязательный шаг, без него данные не придут.

Резервы отдаются Ozon только если соответствующая опция включена в личном кабинете продавца. Модуль напоминает об этом прямо на форме настройки.

Рабочий стол → строка «Резервы» → ⚙ Настройка.

Шаг 3. Сопоставить товары

Резервы приходят по артикулам Ozon. Чтобы модуль понял, какой номенклатуре 1С они соответствуют, товары должны быть сопоставлены.

Рабочий стол → «Каталог» → ▶ Рабочее место → «Загрузить товары ↓» → «⚡ Автосопоставить».

Подробно — Каталог и сопоставление.

Несопоставленный товар попадёт в журнал резервов с ошибкой — но её можно исправить прямо оттуда (см. Шаг 5).

Шаг 5. Журнал резервов и разбор ошибок

Монитор → «Журнал резервов».

Колонки: дата/время, кабинет, артикул Ozon, было, стало, изменение, причина, статус, ид, текст ошибки, признак ошибки.

Кнопки: «Обновить ↺», «🗑 Очистить журнал».

Внизу — поле «ТекстОшибкиДетали» и две кнопки действий по выбранной строке:

Шаг 6. Синхронизация резервов с экрана товаров

Резервы также участвуют в общей синхронизации хаба «Товары».

Рабочий стол → «Остатки» или «Цены» → ▶ Рабочее место → экран «Управление товарами 1С».

Кнопка «Синхронизировать резервы ↑» отправляет данные резервов. В таблице есть колонки «Рез. 1С», «Рез. МП» и «Δ рез» — по ним видно расхождения между резервом в 1С и на маркетплейсе.

Как резервы влияют на остатки

В настройке остатков есть флажок «Вычитать резервы из остатков» (включён по умолчанию).

Когда он включён, на маркетплейс уходит остаток за вычетом резерва — это защищает от продажи товара, который уже зарезервирован под другой заказ.

Различия по конфигурациям 1С

КонфигурацияПоддержка резервов
УТ 11✅ Поддерживается. Резерв ведётся через заказ и регистр резервов товаров
УНФ✅ Поддерживается через регистр резервов запасов
КА 2 / ERP✅ Поддерживается через регистр запасов компании. Организация в документе обязательна
БП 3.0⛔ Не поддерживается. Механика недоступна

В УТ 11 редакции 11.5 отдельного документа «Резервирование запасов» в типовой поставке нет — резерв ведётся через заказ. Кнопка «Создать документ РЗ» создаёт документ той структуры, которая доступна в вашей конфигурации.
