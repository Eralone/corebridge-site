Инструкция для MindBox, SendPulse, Unisender, DashaMail, МойСклад. Механика выгружает контакты и события покупателей в платформу клиентских данных или сервис рассылок.

Работает в двух режимах одновременно:

  • событийный — отправка при наступлении события (заказ создан, оплата получена, отгрузка, отмена…);
  • плановый — синхронизация базы контактов по расписанию.

Шаг 1. Запустить мастер

Каталог проектов → «+ Добавить интеграцию». Шаги 1–2 — см. Мастер подключения.

Шаг 3А → категория marketing (CDP / рассылки). Шаг 3Б → сервис: mindbox, sendpulse, unisender, dashamail или moisklad.

Шаг 3. Настроить маркетинг

Рабочий стол проекта → строка «Маркетинг/CDP» → ⚙ Настройка.

Данные для передачи (профиль контакта)

Отметьте, какие поля контрагента выгружать: Email, телефон, ФИО / наименование, дата рождения, пол, город, ИНН, теги (из групп контрагентов), история заказов, суммы покупок (RFM).

Шаг 4. Рабочее место «Синхронизация контактов»

Рабочий стол → строка «Маркетинг/CDP» → ▶ Рабочее место.

ЭлементНазначение
Последний цикл / ПереданоИтоги последнего запуска
▶ Запустить цикл сейчасПолная синхронизация немедленно
📤 Выгрузить выбранныхОтправить только отмеченные контакты
🔄 ОбновитьПеречитать таблицу
Режимfull / delta
Период дельты (дней)Глубина дельты

Фильтр контрагентов: группа, тип, email, активность.

Статистика: «СтатВсего» (всего контактов), «СтатEmail» (с заполненным email), «СтатСЗаказами» (с историей заказов).

Таблица: №, контрагент, email, количество заказов, статус.

Постраничный вывод: строка «Показано: 200 из 506», кнопки «◀ Пред.» / «След. ▶» и выбор страницы.

Обратите внимание на «СтатEmail». Если он равен нулю, выгружать в сервис рассылок нечего — сначала заполните email в карточках контрагентов 1С.
