Механика отправляет остатки складов 1С на маркетплейс или сайт. Работает по расписанию (по умолчанию — каждые 5 минут).

Это одна из двух механик, которые обязательно нужно настроить руками после создания проекта (вторая — сопоставление товаров). Без выбранных складов остатки не выгружаются вообще.

Шаг 1. Открыть настройку

Рабочий стол проекта → строка «Остатки» → ⚙ Настройка.

Шаг 2. Выбрать склады (обязательно)

Верхний блок «Склады».

Строка «ДиагностикаЗагрузки» показывает, сколько складов прочитано из базы: ✓ Загружено 27 складов из Справочник.Склады · кабинетов: 3.

Поле «ИтогоSKU» показывает суммарное количество позиций по выбранным складам.

Самая частая ошибка при внедрении — пропустить этот шаг. Если ни один склад не выбран, экран «Управление товарами 1С» будет пустым, а на маркетплейс не уйдёт ничего. Для старта проще всего нажать «✓ Выбрать все».

Нажмите «Сохранить».

Форма закрывается по кнопке «Сохранить». Если закрыть по «Отмена», выбор складов не сохранится.

Как это работает

  1. По расписанию (интервал из настройки) модуль читает остатки по выбранным складам.
  2. Если включено «Вычитать резервы» — вычитает резерв, если задан страховой запас — вычитает и его.
  3. Отбрасывает нулевые позиции, если включён соответствующий фильтр.
  4. Отправляет остатки только по сопоставленным товарам.

Несопоставленный товар в выгрузку не попадает — в таблице он виден со значением — в колонке «Артикул МП».
