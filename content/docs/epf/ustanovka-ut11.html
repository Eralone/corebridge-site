CoreBridge EPF — единая внешняя обработка. Один файл содержит все механики: маркетплейсы, сайты, CRM, доставку, оплату, CDP, уведомления, аналитику и произвольные интеграции. Ставится один раз, дальше нужные механики включаются в мастере.

1. Что нужно до начала

  1. Зарегистрированный аккаунт на corebridge.ru с активной лицензией.
  2. JWT-токен — берётся в Личном кабинете, как именно.
  3. Права в 1С: для установки через «Дополнительные отчёты и обработки» нужна роль Администратор либо право «Добавление дополнительных отчётов и обработок».
  4. Открытый исходящий HTTPS до api.corebridge.ru (порт 443) с сервера или рабочего места 1С.

Модуль не открывает входящих портов и не принимает соединений. Данные учёта не выгружаются целиком — на сервер уходят только JSON-события по настроенным механикам.

2. Получение файла

Тот же путь по шагам, со скриншотами каждого экрана кабинета: Первичная настройка.

  1. Войдите в Личный кабинет на corebridge.ru.
  2. Раздел «Файл .epf и JWT-токен».
  3. Выберите конфигурацию 1С:УТ 11.
  4. Скопируйте JWT-токен — он понадобится на Шаге 1 мастера.
  5. Скачайте unified_ut11.epf и сохраните в доступное место на компьютере или сервере 1С.

3. Установка

Вариант А — через «Дополнительные отчёты и обработки» (рекомендуется)

Модуль становится доступен всем пользователям базы из меню раздела, без ручного открытия файла.

  1. НСИ и администрирование → Печатные формы, отчёты и обработки → Дополнительные отчёты и обработки.
  2. Добавить из файла… → Продолжить → выберите unified_ut11.epf.
  3. Укажите раздел, в котором будет отображаться обработка — например Продажи или НСИ и администрирование.
  4. При необходимости задайте список пользователей, которым обработка доступна.
  5. Записать и закрыть.

Если пункт «Дополнительные отчёты и обработки» недоступен — проверьте, что в базе включена соответствующая функциональная опция и что у пользователя есть права администратора.

Вариант Б — открыть файл напрямую

Файл → Открыть → выберите unified_ut11.epf.

Подходит для разовой проверки. Настройки проектов сохраняются в базе, но открывать файл придётся каждый раз вручную.

5. Особенности УТ 11

УТ 11 поддерживает полный набор механик платформы — ограничений нет.

ЧтоКак в УТ 11
Организация в документахНе обязательна
СкладыПолноценный справочник складов, доступен выбор нескольких складов для выгрузки остатков
ЗаказыСоздаётся документ «Заказ клиента»
ОтгрузкаСоздаётся документ реализации
ОплатаКассовые ордера (приходный / расходный)
РезервированиеПоддерживается. Резерв ведётся через заказ и регистр резервов; отдельного документа «Резервирование запасов» в УТ 11.5 нет — см. Резервы
FBM/FBOПоддерживается, включая ордерную схему склада
Маркировка «Честный знак»Поддерживается, включая документы вывода из оборота
Финансовые отчёты МППоддерживаются базовая и расширенные схемы отражения
Типы ценВыбираются из справочника видов/типов цен базы — список подгружается кнопкой на форме настройки цен

6. Автообновление модуля

Модуль раз в сутки проверяет наличие новой версии на сервере платформы. При обнаружении обновления показывается баннер, обновиться можно прямо из интерфейса 1С.

ПараметрЗначение
Интервал проверки24 часа
Что проверяетсяВерсия unified_ut11.epf на сервере платформы
ЗагрузкаПо одноразовой ссылке, действительной ограниченное время
