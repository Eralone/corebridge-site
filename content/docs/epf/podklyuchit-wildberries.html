Wildberries поддерживает 8 механик. Три механики Ozon (резервы, ГТД, акции/Promo) для WB недоступны — соответствующие чекбоксы в мастере не показываются.

Время на подключение: 10–15 минут.

Шаг 1. Запустить мастер

Каталог проектов → «+ Добавить интеграцию». Шаги 1–2 — см. Мастер подключения.

Шаг 2. Категория и сервис

Шаг 3А → категория marketplace (Маркетплейсы). Шаг 3Б → сервис wb.

Схемы работы:

СхемаКогда выбирать
FBSТовар на вашем складе, вы собираете и отгружаете заказы
FBO/FBMТовар на складе Wildberries (поставки FBW)

Схемы взаимоисключающие по составу механик — при необходимости создайте два проекта.

Это не ограничение модуля — соответствующих сценариев нет в API Wildberries.

Шаг 4–6. API, реквизиты, запуск

Ничем не отличаются от Ozon:

  • Шаг 3Г — оставьте ★ Рекомендуемые, частота 15min.
  • Шаг 4 — название («WB Розница»), контрагент, склад отгрузки, договор; организация обязательна только в КА 2 / ERP.
  • Шаг 5 — «✓ Завершить и запустить».

Подробности с иллюстрациями — в разделах «Шаг 4–6» инструкции Как подключить Ozon.

Шаг 7. Настроить после создания

  1. Склады для остатков — строка «Остатки» → ⚙ Настройка → ✓ Выбрать все → Сохранить.
  2. Сопоставить товары — строка «Каталог» → ▶ Рабочее место → «Загрузить товары ↓» → «⚡ Автосопоставить».
  3. Тип цен — строка «Цены» → ⚙ Настройка → выбрать тип цены → Сохранить.
  4. Статусы заказов — строка «Заказы» → ⚙ Настройка → отметить забираемые статусы.

Особенности Wildberries

ОсобенностьКомментарий
Статусы заказовWB использует собственную пару статусов (статус поставщика и статус WB). Модуль приводит их к единому виду в рабочем месте заказов
Поставки FBWРабота с поставками на склад WB — в хабе «Заказы» и в механике поставок при схеме FBO/FBM
Колонки ГТД / Страна / РНПТВ рабочем месте заказов не заполняются — эти данные WB не передаёт
