Механика двигает стадию сделки в CRM при проведении документов в 1С. Направление — только 1С → CRM.

Механика триггерная: срабатывает по факту проведения документа, а не по расписанию.

Шаг 1. Настроить

Рабочий стол проекта → строка «Статусы CRM» → ⚙ Настройка.

Передача статусов из 1С в CRM

Главный флажок «Включить передачу статусов из 1С в CRM» — если он снят, механика не работает.

Какие события передавать

Отметьте события, которые должны двигать стадию сделки:

СобытиеКогда срабатывает
Заказ создан / подтверждёнПри проведении документа заказа
Заказ отгруженПри проведении документа отгрузки
Заказ оплаченПри проведении документа оплаты
Заказ отменёнПри отмене проведения заказа
Счёт выставленПри проведении счёта на оплату
Произвольный статус (ручной выбор менеджером)Менеджер выбирает стадию вручную

Рядом с каждым событием — поле для указания целевой стадии.

Настройки повтора при ошибке

ПараметрНазначение
Повторять при ошибкеВключить повторные попытки
Попыток (1–5)Сколько раз пробовать
Интервал между попыткамиПауза между попытками
Действие при недоступностиЧто делать, если CRM не отвечает после всех попыток

Маппинг статусов 1С → стадий CRM

Кнопка «Открыть n8n воркфлоу →».

Важно: соответствие «событие 1С → конкретная стадия воронки CRM» настраивается на стороне платформы, в воркфлоу n8n, а не в 1С. В модуле вы выбираете, какие события отправлять; куда именно они попадут в воронке — задаётся в воркфлоу.

Кнопки: «Сохранить», «Отмена», «Проверить соединение», «Монитор статусов».

Шаг 2. Монитор статусов

Рабочий стол → строка «Статусы CRM» → ▶ Рабочее место. Либо кнопка «Монитор статусов» на форме настройки.

Монитор показывает очередь передачи, историю отправленных статусов и ошибки, которые не удалось передать после всех повторов. Кнопка «Обновить» перечитывает данные.

Из монитора можно повторить неудавшиеся отправки.

Различия по конфигурациям 1С

КонфигурацияОсобенности
УТ 11Все события доступны: заказ, отгрузка, оплата, счёт
УНФВсе события. Отмена заказа определяется по признаку отмены пользователем
КА 2 / ERPВсе события. Организация обязательна, контрагент ищется через партнёра
БП 3.0⚠️ Заказа клиента нет: «Заказ создан / подтверждён» отрабатывает по счёту на оплату. Отдельного события отмены заказа нет — используйте «Произвольный статус»

Частые проблемы

СимптомРешение
Статусы не уходят в CRMСнят главный флажок «Включить передачу статусов из 1С в CRM»
Уходят не все событияСоответствующее событие не отмечено в блоке «Какие события передавать»
Стадия в CRM меняется не на туСоответствие настраивается в воркфлоу n8n — кнопка «Открыть n8n воркфлоу →», а не в 1С
Ошибки накапливаются в монитореПроверьте доступность CRM и «Проверить соединение». Затем повторите отправку из монитора
CRM была недоступна, события потерялисьВключите «Повторять при ошибке» и задайте количество попыток — тогда события будут переотправлены
В БП 3.0 не работает отмена заказаОжидаемо. Используйте событие «Произвольный статус»
