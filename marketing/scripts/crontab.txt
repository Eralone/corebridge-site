# Расписание маркетингового контура corebridge.ru
# Ставится под пользователем deploy:  crontab marketing/scripts/crontab.txt
# Проверить, что встало:              crontab -l
#
# ⚠️ Часы сервера — UTC (проверено `timedatectl`, зона Etc/UTC). Москва = UTC+3,
# поэтому слева стоит UTC, а в комментарии — привычное московское время.
# Если когда-нибудь переведёшь сервер на Europe/Moscow, эти строки надо сдвинуть
# на 3 часа вперёд, иначе всё поедет.
#
# Логи nginx ротируются в 06:25 UTC (стандартный /etc/cron.daily), поэтому сбор
# стоит раньше — иначе сутки данных теряются безвозвратно.
#
# ── Чего здесь нет и почему ─────────────────────────────────────────────────
# Прогонов языковой модели по расписанию нет: claude CLI на сервер не ставится
# (решение от 2026-08-20, работа идёт через VS Code). Разбор, тексты и гипотезы
# запускаются в сессии командами /mkt-* — см. .claude/skills/.
#
# Поэтому cron делает ровно то, что должно работать без человека и без модели:
# собирает данные, следит за сайтом и присылает цифры. Данные накапливаются
# каждый день независимо от того, открывал ли кто-нибудь сессию.

SHELL=/bin/bash
PATH=/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin
MKT=/opt/corebridge-site/marketing/scripts

# Каждые 15 минут: сайт жив, 5xx, битые ссылки, сертификат,
# новая заявка / регистрация / оплата
*/15 * * * * $MKT/run.sh watch

# 02:40 UTC = 05:40 МСК — выгрузка за вчера
40 2 * * * $MKT/run.sh collect

# 03:00 UTC = 06:00 МСК — сводка цифрами в Telegram.
# В ней же напоминание, если разбора не было несколько дней.
0 3 * * * $MKT/run.sh digest

# 05:00 UTC = 08:00 МСК понедельник — итоги недели цифрами.
# Вердикты по гипотезам и новые гипотезы — руками, командой /mkt-weekly.
0 5 * * 1 $MKT/run.sh digest --week
