# Маркетинговый агент corebridge.ru


## Контроль

- Раз в неделю читайте `logs/*.json` — там `total_cost_usd`, следите за расходом
- Ветки `claude/*` не мержатся автоматически. Смотрите diff перед мержем.
- Раз в месяц перечитывайте `knowledge/` — если там накопился мусор,
  агент будет опираться на мусор
- Если два прогона подряд дали пустые отчёты — проблема в данных или в CLAUDE.md,
  не в промпте

## Чего система не умеет

- Не видит поисковые запросы без Вебмастера/GSC — это единственная
  обязательная внешняя зависимость
- Не оценивает качество лидов, если статус сделки не попадает в `mkt_events`
- Не работает с платной рекламой — там нужны отдельные доступы и деньги,
  сознательно вынесено за рамки
