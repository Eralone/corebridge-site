## 2. Правила для текста

- Опирайся на факты о продукте из CLAUDE.md. Чего не знаешь — маркер
  `[ДАННЫЕ: нужна цифра по X]`, не выдумывай.
- Структура под поисковый интент: заголовок отвечает на запрос,
  первый абзац даёт ответ, дальше — детали.
- Никакого «в современном мире», «в наше время», воды во вступлении.
- Проверь по `knowledge/pages.md`, что не создаёшь каннибализацию:
  если под этот запрос уже есть страница — дорабатывай её.
- Внутренние ссылки на 2–3 релевантные существующие страницы.

## 3. Куда класть

- Тексты — `content/drafts/YYYY-MM-DD-<slug>.md`. В шапке файла:
  площадка, целевой запрос или для какой страницы, какая гипотеза,
  какой формат и стиль проверяется, что человек должен проверить
  перед публикацией.
- Технические правки (title, description, разметка, скорость) — кодом
  в ветку `claude/content-YYYY-MM-DD`, не более 3 страниц за прогон.
  **Не запускай `npm run build`** — это рабочий каталог прода.
  Проверяй `npx tsc --noEmit`.
- Если правишь страницу в рамках эксперимента — обязательно зафиксируй
  базлайн метрики в файле гипотезы ДО правки.

## 4. Отправь черновик человеку

Публикует он, и до тех пор текст никому не виден:

```bash
python3 scripts/notify_telegram.py --file content/drafts/<файл>.md \
        --title "Черновик: <куда> — <о чём>"
```

Если черновиков несколько, шли по одному сообщению на каждый: их будут читать
с телефона и публиковать по одному.
