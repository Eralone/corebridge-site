## 2. Проверь по одной технической теме за прогон

Не всё сразу — по одной, до результата:

- Коды ответов: 404 и 5xx на страницах, куда ведут наши же ссылки
- Скорость первого экрана (`npm run inspect` уже умеет обходить страницы)
- Микроразметка: Organization, BreadcrumbList, FAQPage на подходящих страницах
- Дубли: две страницы под один запрос — по `knowledge/pages.md`
- Длина title (>60) и description (>160): в выдаче обрезается
- Внутренняя перелинковка: страницы без входящих ссылок с других страниц
- Картинки без alt
