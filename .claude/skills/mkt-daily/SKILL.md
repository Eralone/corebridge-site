# Ежедневный разбор

Данные за вчера уже собраны cron'ом в 05:40 МСК. Твоя работа — объяснить их.

1. Прочитай `marketing/CLAUDE.md` целиком — это правила работы, они важнее
   твоих общих представлений о маркетинге.
2. Выполни `marketing/prompts/10_daily_metrics.md` буквально.

Если сбор почему-то не отработал, запусти руками:

```bash
cd marketing/scripts && ./run.sh collect
```

Ограничения, которые нарушать нельзя (подробно — раздел 5 `marketing/CLAUDE.md`):
не писать в продуктовую БД, не запускать `npm run build`, не публиковать
ничего наружу, не трогать страницы из `marketing/knowledge/protected_pages.md`.
