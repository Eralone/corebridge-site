## 1. Что это за проект (в двух абзацах)

Превратить 27 готовых HTML-страниц дизайна в работающий сайт `corebridge.ru` на Next.js —
визуально **1:1** с макетом, с живым бэкендом. Бэкенд (`/opt/corebridge`, репозиторий
`corebridge-server`) уже реализовал почти всё нужное API; сайт его потребляет.

Дизайн — это **референс раскладки, шрифтов и форм**. Значения внутри (имена, суммы, счётчики,
названия компаний) — иллюстративные заглушки. Вёрстку переносим 1:1, данные подставляем из API.

## 2. Жёсткие ограничения — нарушать нельзя

| # | Ограничение | Почему |
|---|---|---|
| 1 | **`/opt/corebridge` не править руками** | автодеплой с локального ПК затрёт. Нужны правки бэкенда → промт в `Documents/prompts/` |
| 2 | **`/lk/*` занят API** | nginx проксирует в lk-api:3000. Экраны ЛК под этим префиксом размещать нельзя → `/dashboard`, `/epf`, а не `/lk/dashboard` |
| 3 | **`/admin/*` занят API** | nginx проксирует в admin:3003. На `admin.corebridge.ru` UI живёт в корне, разводит `middleware.ts` |
| 4 | **Никакого Tailwind и shadcn** | их preflight переопределяет `site.css` и ломает попиксельное совпадение (`implementation_strategy.md` §3) |
| 5 | **`design-source/` только на чтение** | это эталон. Правки живут в реализации, а не в эталоне |
| 6 | **Прайс не хардкодить** | только `GET /lk/plans`. Канон цифр — сервер (S2 привёл каталог к `pricing.html`) |
| 7 | **Не публиковать выдуманные данные** | `contacts.html` (реквизиты несуществующего ООО) и `for-business.html` (отзывы от имени выдуманных людей) — блоки не переносим |
| 8 | **`listen [::]:443` не писать** в своих vhost | nginx слушает 443 только на IPv4; иначе vhost станет default для IPv6 и отдаст свой сертификат чужому домену |
| 9 | **SMS не существует и не появится** | второй фактор и уведомления только через Telegram. Колонку SMS в матрице не рисовать |

## 5. Следующая задача

### [ ] Э0.1 — `middleware.ts`

**Зачем:** чинит коллизию путей админки (сейчас экран недостижим) и закрывает ЛК от неавторизованных.

**Что сделать:**
1. **Разводка субдоменов.** На `admin.corebridge.ru` переписывать входящий путь на внутренний роут:
   `/` → `/admin`, `/users` → `/admin/users`, `/integrations` → `/admin/integrations`.
   Путь `/admin/*` **не трогать** — он уходит в nginx → 3003 (API).
   Обратно: админские роуты не должны открываться с `corebridge.ru`, и наоборот.
2. **Guard ЛК.** Для `/dashboard`, `/epf`, `/my-integrations`, `/billing`, `/settings`,
   `/support`, `/workflows` — проверка `GET /lk/auth/session`; при 401 → редирект на `/login`.
3. Обработать `403 TENANT_BLOCKED` и `403 TENANT_PENDING_DELETION` (разные экраны:
   «заблокирован» и «аккаунт удаляется»).

**Проверить после:** `admin.corebridge.ru/` отдаёт экран админки (сейчас 200, но это заглушка
из `(admin)/admin`), `/admin/health` по-прежнему 403 от whitelist, `corebridge.ru/dashboard`
без сессии редиректит на `/login`.

**Источники:** README раздел «Коллизия путей в админке», `site_S8_S9_RESPONSE.md` §7 (`tenant_status`).

## 8. Мелочи, которые легко забыть

- `npm run dev` и `npm start` слушают **3005** (3000 занят контейнером lk-api).
- Сервис: `sudo systemctl restart corebridge-site`, логи `journalctl -u corebridge-site`.
- nginx-конфиги в `/etc/nginx/sites-available/` — **обычные файлы** (не симлинки),
  автодеплой бэкенда их не трогает. Копии в `deploy/nginx/`.
- `sudo` без пароля доступен.
- Редирект после входа и magic-link сервер ведёт на **`/dashboard`**.
- Приглашения в команду сервер шлёт на `${LK_BASE_URL}/lk/invite/accept?token=…` —
  но `/lk/*` занят API. **Проверить, куда реально ведёт ссылка**, и согласовать с бэкендом.
- Ошибка смены пароля у Яндекс-аккаунта — код `OAUTH_ACCOUNT` (не `GOOGLE_ACCOUNT`).
- В каталоге `assets/integrations-data.js` 34 записи, но одна («Иное») не сервис → «33 сервиса».
- `assets/integrations-manager.js` (67 КБ) — инструкции «где взять ключи» для 26 сервисов.
  Модалку каталога убираем, но **инструкции перенести** в форму ввода ключей.
