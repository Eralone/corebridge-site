# P-01 · Визуал лендинга (Landing Page)

## Контекст проекта

Ты создаёшь **только визуальный макет** страницы — без механик, без логики, без JS-обработчиков.
Цель: сгенерировать production-ready HTML/CSS компонент (или React JSX), который будет передан верстальщику.

## Файлы для изучения (загружены вместе с этим промтом)

- **`MC9_landing_mechanics.docx`** — изучи раздел «Структура страницы» и «Блоки». Используй названия секций, их порядок и описание контента. **Механики (onClick, fetch, состояния) — игнорируй.**
- **`platform_architecture_v3_updated.md`** — найди описание продукта CoreBridge: позиционирование, целевая аудитория, ключевые преимущества. Используй для копирайтинга заглушек.
- **`CoreBridge_filtered.csv`** — семантическое ядро. Колонки: keyword, frequency, intent. Возьми топ-20 ключевых слов с высокой частотностью и intent=informational/commercial. Вставь их **органично** в заголовки (H1, H2), подзаголовки и мета-описания секций. Не спамь — 1–2 ключа на секцию.
- **`Сайт_drawio.svg`** — схема сайта. Найди узел «Landing» / «Главная» и посмотри, какие дочерние блоки к нему привязаны.

## Цветовая палитра и типографика

- Основной цвет бренда: **#0A2463** (тёмно-синий) и **#3E92CC** (акцентный голубой)
- Фон: белый (#FFFFFF) и светло-серый (#F4F6FA) для чередования секций
- Акцент / CTA: **#FF6B35** (оранжевый) или **#3E92CC**
- Шрифт: Inter или системный sans-serif, заголовки 700, текст 400
- Радиус карточек: 12px, тени: 0 4px 24px rgba(0,0,0,0.08)

## Структура страниц (секции в порядке сверху вниз)

### 1. Навигация (Header / Navbar)
- Логотип слева (текст «CoreBridge» или SVG-заглушка)
- Меню: Возможности, Тарифы, Документация, Интеграции
- Справа: кнопка «Войти» (outline) + «Начать бесплатно» (filled, акцентный цвет)
- Sticky, белый фон с тонкой тенью при скролле (CSS-класс, без JS)

### 2. Hero-секция
- H1 — главный заголовок (вставь ключевое слово с высокой частотностью из CSV, например «интеграция бизнес-процессов» или «автоматизация задач»)
- Подзаголовок — 2–3 строки описания ценности продукта
- Два CTA: «Попробовать бесплатно» (primary) + «Смотреть демо» (secondary/ghost)
- Справа или снизу: hero-иллюстрация (SVG-заглушка с абстрактным дашбордом или placeholder 600×400)
- Фон: градиент от #0A2463 до #3E92CC или белый с декоративными фигурами

### 3. Логотипы клиентов / Social proof
- Строка «Нам доверяют»
- 5–6 серых логотипов-заглушек (прямоугольники 120×40)

### 4. Блок преимуществ (Features)
- H2 с ключевым словом из CSV
- 3–4 карточки в сетке: иконка (SVG или emoji), заголовок, 2–3 строки описания
- Примеры фич: «Готовые интеграции», «Автоматизация без кода», «Безопасность данных», «Аналитика в реальном времени»

### 5. Как это работает (How it works)
- Нумерованные шаги (1, 2, 3): иконка + заголовок + краткое описание
- Горизонтально на desktop, вертикально на mobile

### 6. Тарифы (Pricing preview)
- H2 с ключевым словом (например «тарифы CoreBridge», «стоимость интеграции»)
- 3 карточки: Free / Pro / Enterprise
- Каждая: название, цена (заглушка «от X ₽/мес»), список из 4–5 фич (✓ / ✗), CTA-кнопка
- Карточка Pro — визуально выделена (border акцентным цветом, бейдж «Популярный»)

### 7. Testimonials / Отзывы
- 3 карточки с аватаром (круглый placeholder), именем, должностью, текстом отзыва

### 8. CTA-баннер
- Полноширинный блок с фоном акцентного цвета
- Большой заголовок + кнопка «Начать бесплатно»

### 9. Footer
- 4 колонки: логотип + описание, Продукт, Компания, Поддержка
- Ссылки-заглушки, копирайт, соцсети (иконки)

## SEO-требования (только разметка, без серверного кода)

- `<title>` и `<meta name="description">` — подобрать из топ ключей CSV
- Правильная иерархия заголовков: один H1, несколько H2, H3 внутри секций
- `alt` у всех img/svg-заглушек — описательный текст с ключевым словом
- Семантические теги: `<header>`, `<main>`, `<section>`, `<footer>`, `<nav>`, `<article>`
- `aria-label` на кнопках и навигации

## Требования к коду

- Чистый HTML + CSS (или React JSX + Tailwind / CSS-модули)
- Без JavaScript-механик (нет fetch, нет useState для форм)
- Адаптив: desktop (1280px) → tablet (768px) → mobile (375px)
- Все тексты — осмысленные русскоязычные заглушки (не Lorem ipsum)
- Комментарии в коде: `<!-- СЕКЦИЯ: Hero -->` для удобства верстальщика
