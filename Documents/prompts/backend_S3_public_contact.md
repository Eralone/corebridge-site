# Промт для `corebridge-server` — пакет S3: публичная форма контактов

> Приоритет: средний (нужен к этапу Э4 — лендинг и страница контактов).
> Составлено сайтом 2026-07-26, сверено с `docs/API_ENDPOINTS.md`.

## Что нужно

Публичного эндпоинта приёма заявок нет вообще. Нужен для `contacts.html` и CTA-форм лендинга
(`index.html`, `for-business.html`, `pricing.html`).

```
POST /api/v1/public/contact          (без auth)
body {
  "name", "email", "phone"?, "message",
  "source"?: "landing" | "pricing" | "contacts" | "for_business",
  "honeypot"?: ""                    // скрытое поле формы; если непустое — тихо вернуть 202 и не обрабатывать
}
→ 202 { "received": true, "ref": "REQ-2141" }     // ref нужен, чтобы показать человеку номер обращения
errors:
  400 VALIDATION_ERROR { fields: ["email"] }
  429 TOO_MANY_REQUESTS                            // rate-limit по IP, предлагаю 5 / час
```

Дальше сервер шлёт заявку менеджеру — через n8n / Telegram / email, как удобнее в текущей
инфраструктуре (`TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в `.env` уже есть).

## Почему без капчи

Внешние капчи (Google reCAPTCHA, hCaptcha) — иностранные сервисы, по решению продукта их не
используем. Защита: rate-limit по IP на nginx/приложении + honeypot-поле + проверка, что
`message` не пустой и не однотипный спам. Если этого мало и пойдёт спам — обсудим Яндекс SmartCaptcha
отдельным пакетом.

## Где размещать

Префикс `/api/v1/*` за nginx уходит в **bridge (3001)** с Bearer-JWT-мидлварой. Публичный маршрут
там надо явно исключить из проверки токена. Если это неудобно — предложи свой путь
(например `/lk/contact` в lk-api, где уже есть публичные маршруты `/lk/plans`, `/lk/auth/*`) и
сообщи финальный. Сайту всё равно, лишь бы путь был зафиксирован.
