# Промт для `corebridge-server` — пакет S5: список сессий и выход на всех устройствах

> Приоритет: средний (этап Э5 — `settings.html`, блок «Активные сессии»).
> Составлено сайтом 2026-07-26.

## Проблема хранения

Сессия лежит в Redis DB=1 **одиночным ключом** `lk_session:<session_id>` со значением
`{user_id, tenant_id, role, ip, created_at}`. Вторичного индекса «все сессии пользователя» нет,
поэтому ни показать список, ни завершить конкретную сессию сейчас нельзя.

## Что просит сайт — двумя шагами

### Шаг 1 (минимум, реализуем почти сразу) — «Выйти на всех устройствах»

```
POST /lk/sessions/logout-others      (cookie lk_session)
→ 200 { "revoked": 3 }               // сколько сессий погашено, кроме текущей
errors: 401
```

Для этого достаточно **ленивого индекса**: при каждом создании сессии добавлять `session_id` в
`SET lk_user_sessions:<user_id>` с тем же TTL. Тогда `logout-others` = прочитать сет, удалить все
ключи кроме текущего, почистить сет.

Этот эндпоинт нужен **также** для пакета S1 (после сброса пароля надо погасить все сессии) —
так что индекс всё равно придётся завести. Сделай его здесь.

### Шаг 2 (полный список) — если индекс уже есть, стоит дешево

```
GET /lk/sessions                     (cookie)
→ 200 { "sessions": [
    { "id":"…", "ip":"77.90.61.5", "user_agent":"Mozilla/5.0 …",
      "created_at":"2026-07-26T10:00:00Z", "last_seen_at":"…", "current": true }
  ] }

DELETE /lk/sessions/:id              (cookie)
→ 200 { "ok": true }
errors: 404 SESSION_NOT_FOUND · 409 CANNOT_REVOKE_CURRENT · 401
```

Потребуется дописывать в значение сессии `user_agent` и обновлять `last_seen_at` — сейчас их нет.
`user_agent` берётся из заголовка запроса при логине.

## Приоритеты

**Шаг 1 обязателен** (нужен для S1). Шаг 2 — по возможности; если решишь отложить, сообщи, и сайт
покажет только кнопку «Выйти на всех устройствах» вместо списка устройств (по дизайну блок
допускает такую деградацию).

## Definition of Done

- [ ] Ленивый индекс `lk_user_sessions:<user_id>` заведён (TTL синхронен с сессией)
- [ ] `POST /lk/sessions/logout-others` реализован, покрыт тестом
- [ ] Решено и сообщено: делаем ли Шаг 2 (список + отзыв конкретной сессии) сейчас или позже
- [ ] Если Шаг 2 делается — в значение сессии добавлены `user_agent` и `last_seen_at`
