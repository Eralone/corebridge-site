Как подключить службу доставки

Инструкция для СДЭК, Почты России и ЯМ Доставки. Механика создаёт заявки на доставку по документам отгрузки 1С и отслеживает трек-номера.

Шаг 1. Запустить мастер

Каталог проектов → «+ Добавить интеграцию». Шаги 1–2 — см. Мастер подключения.

Шаг 3А → категория services_delivery (Доставка). Шаг 3Б → сервис: cdek, pochta или ym_delivery.

Шаг 2. Механики

МеханикаЧто делает
Заявка на доставкуСоздаёт заявки в службе доставки и отслеживает статусы
Печать этикетокПечать этикеток отправлений — см. Этикетки

Шаг 3Г — оставьте ★ Рекомендуемые. Шаг 4 — реквизиты. Шаг 5 — «✓ Завершить и запустить».

Шаг 3. Настроить доставку

Рабочий стол проекта → строка «Доставка» → ⚙ Настройка.

Проверка

Поле «Сервис» и кнопка «Тест подключения» — начните с неё.

Режим создания заявок

ПараметрЗначенияКомментарий
Создавать заявку при отгрузкеДа / НетОсновной переключатель
Режим созданияauto / confirm / manualauto — заявка создаётся сразу; confirm — с подтверждением в диалоге; manual — только по кнопке

Отправитель

Город отправления, код города (для СДЭК), адрес отправления, индекс, контактное лицо, телефон отправителя, склад отгрузки.

Параметры сервиса

ПараметрНазначение
Код тарифаТариф службы доставки
Тип упаковкиВид упаковки
Страховать грузДа / Нет
Формат этикеткиНапример A6
Хрупкий грузДа / Нет
Дней хранения в ПВЗСрок хранения в пункте выдачи

Опции механики

ПараметрНазначение
Записывать трек-номер в документСохранять трек в документе 1С
Реквизит для трек-номераИмя реквизита, например ТрекНомер
Обновлять статусы трекингаПериодически подтягивать статус отправления
Интервал обновления (мин)По умолчанию 60
Автопечать этикеткиПечатать этикетку сразу после создания заявки

Нажмите «Сохранить».

Шаг 4. Рабочее место «Доставка»

Рабочий стол → строка «Доставка» → ▶ Рабочее место.

ЭлементНазначение
Сервис доставкиПроект
Фильтр → Статус + Применить / СброситьФильтр по статусу отправления
Создать заявкуСоздать заявку вручную
Отменить заявкуОтменить выбранную заявку
ОтследитьЗапросить актуальный статус по трек-номеру
Обновить ↺Перечитать таблицу
Настройка доставкиОткрыть форму настройки

Таблица «Отправления»: ID заявки, трек-номер, сервис, статус, получатель, город, стоимость, время обновления.

Как это работает

  1. В 1С проводится документ отгрузки.
  2. В зависимости от режима создания заявка формируется автоматически, с подтверждением или ждёт ручного запуска.
  3. Служба доставки возвращает трек-номер — он записывается в документ, если включена соответствующая опция.
  4. По интервалу обновления модуль подтягивает статусы отправлений.

Различия по конфигурациям 1С

КонфигурацияДокумент-источник отгрузкиДанные получателя

УНФРасходная накладнаяИз контрагента
КА 2 / ERPРеализация товаров и услуг⚠️ Из партнёра. Организация обязательна
БП 3.0Реализация товаров и услугИз контрагента. Склад в настройке недоступен

Частые проблемы

СимптомРешение
«Тест подключения» не проходитПроверьте, что интеграция со службой доставки настроена в Личном кабинете платформы
Заявки не создаются автоматически«Создавать заявку при отгрузке» = Нет, либо режим manual. Проверьте настройку
Заявка создалась, трек-номер не попал в документНе включена опция «Записывать трек-номер в документ» или неверно указано имя реквизита
Статусы отправлений не обновляютсяНе включено «Обновлять статусы трекинга». Либо нажмите «Отследить» вручную
Таблица отправлений пустаяНажмите «Обновить ↺»; проверьте фильтр по статусу — сбросьте его кнопкой «Сбросить»
Не заполняется адрес получателяВ КА 2 / ERP данные берутся из партнёра — проверьте карточку партнёра
Не печатается этикеткаМеханика этикеток не подключена или не настроен принтер — см. Этикетки
