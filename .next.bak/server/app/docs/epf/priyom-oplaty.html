Как подключить приём оплаты

Инструкция для платёжных сервисов: ЮKassa, СБП, Тинькофф, Сбер. Механика получает события об оплатах и возвратах и создаёт по ним документы в 1С.

Шаг 1. Запустить мастер

Каталог проектов → «+ Добавить интеграцию». Шаги 1–2 — см. Мастер подключения.

Шаг 3А → категория services_payment (Оплата). Шаг 3Б → сервис: yukassa, sbp, tinkoff или sber.

Шаг 2. Механики

Механика одна — «Обработка оплаты». Она отмечена по умолчанию.

Шаг 3Г — ★ Рекомендуемые. Шаг 4 — реквизиты. Шаг 5 — «✓ Завершить и запустить».

Шаг 3. Настроить обработку оплаты

Рабочий стол проекта → строка «Оплата» → ⚙ Настройка.

ПараметрЗначенияНазначение

Создавать документ при возвратеДа / НетФормировать документ по возврату средств
Привязывать к заказу (по order_id)Да / НетСвязывать оплату с заказом

Фильтры

БП 3.0⚠️ Поступление на расчётный счёт⚠️ Списание с расчётного счёта

Как это работает

  1. Платёжный шлюз сообщает платформе об оплате или возврате.
  2. Платформа проверяет событие и кладёт его в очередь проекта.
  3. Модуль забирает событие при очередном опросе.
  4. Проверяет дубли по payment_id, находит заказ (если включена привязка) и создаёт документ.
  5. Результат виден в журнале оплат.

Частые проблемы

СимптомРешение
Журнал пустойНажмите «Обновить ↺»; сбросьте фильтры кнопкой «Сбросить»; проверьте статус проекта (Активен) и нажмите «▶ Запустить цикл сейчас»
Платёж пришёл, документ не созданПроверьте реквизиты Шага 4 мастера: контрагент, касса/счёт; в КА 2 / ERP — организацию. Затем «Повторить обработку»
Документ создан, но не проведёнСнят параметр «Автопроведение при оплате», либо базе не хватает реквизитов — проведите вручную
Один платёж обработан дваждыВключите «Проверять дубли (по payment_id шлюза)»
Оплата не привязывается к заказуПроверьте «Привязывать к заказу (по order_id)» и поле «Проект-источник заказов»
Не создаётся контрагент по плательщикуВключите «Создавать контрагента по данным плательщика»
В БП создан банковский документ вместо кассовогоОжидаемо — в БП 3.0 используются банковские документы
Нет уведомления в TelegramМеханика уведомлений не подключена отдельным проектом
