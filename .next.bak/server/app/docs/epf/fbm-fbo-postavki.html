Как настроить поставки FBM / FBO

Механика ведёт поставки товара на склад маркетплейса: формирование поставки, упаковка по грузовым местам, отгрузка.

Механика доступна только при схеме работы FBO/FBM. При схеме FBS она скрыта в мастере — это не ошибка, а разделение сценариев.

Шаг 1. Создать проект со схемой FBO/FBM

В мастере на Шаге 3Б отметьте схему «FBO/FBM — товар на складе маркетплейса (поставки)».

Схемы FBS и FBO/FBM взаимоисключающие по составу механик. Если вы уже работаете по FBS и хотите добавить поставки — создайте второй проект на тот же кабинет, выбрав схему FBO/FBM.

На Шаге 3В появится чекбокс механики поставок.

Шаг 2. Настроить механику

Рабочий стол проекта → строка «FBM» → ⚙ Настройка.

Здесь задаются параметры формирования поставок: склад-источник, режим создания документов, правила упаковки. Состав полей зависит от площадки и конфигурации 1С.

Нажмите «Сохранить».

Шаг 3. Рабочее место поставок

Рабочий стол → строка «FBM» → ▶ Рабочее место.

Фильтр

Поле «Кабинет» и кнопки-фильтры по стадиям:

Типовой цикл работы

  1. + Новая поставка — создать поставку, выбрать склад маркетплейса и товары.
  2. Упаковка → — распределить товар по грузовым местам (коробам, паллетам).
  3. Напечатать этикетки грузовых мест — см. Этикетки.
  4. ✓ Отгрузить — подтвердить отгрузку; модуль сообщает площадке и создаёт документ отгрузки в 1С.
  5. Поставка уходит в фильтр «Архив».

Различия по конфигурациям 1С

КонфигурацияОсобенности
УТ 11Полная поддержка, включая ордерную схему склада (расходный ордер)
УНФПоддерживается. Ордерная схема — нет
КА 2 / ERPПоддерживается, организация обязательна. Ордерная схема — нет
БП 3.0Поддерживается ограниченно — складского учёта в полном объёме нет

Ордерная схема включается флажком «На складе включена ордерная схема» в настройке отгрузки.

Частые проблемы

СимптомРешение
Механики нет на Шаге 3ВВыбрана схема FBS. Вернитесь на Шаг 3Б и отметьте FBO/FBM, либо создайте отдельный проект
Таблица поставок пустаяНажмите «↺ Обновить»; проверьте фильтр (по умолчанию может стоять не «Все»); убедитесь, что поставки созданы
Не создаётся поставкаПроверьте реквизиты Шага 4 мастера: склад отгрузки, контрагент; в КА 2 / ERP — организацию
Товар не попадает в поставкуТовар не сопоставлен. См. Каталог и сопоставление
Не печатаются этикетки грузовых местМеханика этикеток не подключена либо не настроен принтер. См. Этикетки
Нужны обе схемы (FBS и FBO)Создайте два проекта на один кабинет
