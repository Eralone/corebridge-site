Установка CoreBridge EPF — 1С:Управление нашей фирмой

ПараметрЗначение
Файл модуляunified_unf.epf
Конфигурация1С:Управление нашей фирмой (УНФ)
Сервер платформыhttps://api.corebridge.ru
Платформа 1С8.3.14 и выше (рекомендуется 8.3.22+)
Режим работыУправляемое приложение: тонкий, толстый или веб-клиент
Сетевые требованияТолько исходящий HTTPS на api.corebridge.ru:443
Прямые вызовы API маркетплейсовНет — весь обмен идёт через сервер платформы

CoreBridge EPF — единая внешняя обработка. Один файл содержит все механики платформы; нужные включаются в мастере при создании проекта.

1. Что нужно до начала

  1. Аккаунт на corebridge.ru с активной лицензией.
  2. JWT-токен из Личного кабинета — как его получить.
  3. Права администратора в 1С (для установки через «Дополнительные отчёты и обработки»).
  4. Открытый исходящий HTTPS до api.corebridge.ru:443.

Модуль не открывает входящих портов. На сервер уходят только JSON-события по настроенным механикам.

2. Получение файла

Тот же путь по шагам, со скриншотами каждого экрана кабинета: Первичная настройка.

  1. Личный кабинет на corebridge.ru → «Файл .epf и JWT-токен».
  2. Конфигурация — 1С:УНФ.
  3. Скопируйте JWT-токен.
  4. Скачайте unified_unf.epf.

3. Установка

Вариант А — через «Дополнительные отчёты и обработки» (рекомендуется)

  1. Компания → Администрирование → Печатные формы, отчёты и обработки → Дополнительные отчёты и обработки.
  2. Добавить из файла… → Продолжить → unified_unf.epf.
  3. Укажите раздел размещения (например Продажи).
  4. Записать и закрыть.

Вариант Б — открыть файл напрямую

Файл → Открыть → unified_unf.epf. Подходит для разовой проверки.

4. Первый запуск

Откроется вкладка CoreBridge. Каталог проектов → «+ Добавить интеграцию».

Полный разбор шагов — Мастер подключения.

ШагЧто делаете
1. ПодключениеURL + JWT → Проверить подключение
2. Конфигурация 1СОпределяется автоматически как unf
3А–3ГКатегория → сервис и схема → механики → API и частота
4. РеквизитыНазвание, контрагент, склад, договор
5. Запуск✓ Завершить и запустить

5. Особенности УНФ

ЧтоКак в УНФ
Организация в документахНе обязательна
СкладыПолноценный складской учёт, доступен выбор нескольких складов
ЗаказыСоздаётся документ заказа клиента
ОтгрузкаСоздаётся расходная накладная
ОплатаКассовые ордера (приходный / расходный)
РезервированиеПоддерживается через регистр резервов запасов
Маркировка «Честный знак»Поддерживается; структура табличной части кодов маркировки отличается от УТ 11 — заполняется автоматически
Финансовые отчёты МПБазовая схема отражения (отчёт комиссионера). Расширенные схемы недоступны
FBM/FBOПоддерживается. Ордерная схема склада — не поддерживается
Справочник партнёровОтсутствует, работа ведётся напрямую с контрагентами
Типы ценСписок подгружается кнопкой на форме настройки цен

6. Автообновление модуля

Раз в сутки модуль проверяет наличие новой версии unified_unf.epf на сервере платформы. При наличии обновления предлагает обновиться прямо из интерфейса 1С.

7. Диагностика

СимптомЧто проверить
На Шаге 1 статус подключения пустойДоступность api.corebridge.ru:443, прокси/файрвол, срок действия JWT
Проект создан, но данных нетСтатус проекта = Активен; нажать «▶ Запустить цикл сейчас»
Пустая таблица в рабочем местеНажать «Обновить» на самой форме
Остатки не выгружаютсяВ ⚙ Настройка механики «Остатки» не выбраны склады → ✓ Выбрать все → Сохранить
Товары не синхронизируютсяНе выполнено сопоставление номенклатуры — см. Каталог и сопоставление
Нет расширенных схем финансового отчётаОжидаемо: в УНФ доступна только базовая схема
Не работает ордерная схема FBMОжидаемо: ордерная схема доступна только в УТ 11
