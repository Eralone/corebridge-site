Как настроить заказы и отгрузку

Две механики, работающие в паре:

  • Получение заказов FBS/FBO — забирает заказы с площадки и создаёт документы в 1С;
  • Подтверждение отгрузки — создаёт документ отгрузки и сообщает площадке об отправке.

Обе входят в хаб «Заказы» — у них общее рабочее место CoreBridge. Заказы. К этому же хабу относятся механики ГТД и этикеток.

Шаг 1. Настроить получение заказов

Рабочий стол проекта → строка «Заказы» → ⚙ Настройка.

Схема работы

Поле «Схема» — FBS, FBO или realFBS. Задаётся на Шаге 3Б мастера и здесь отображается.

Какие статусы заказов забирать

СтатусКодПо умолчанию
Ожидает упаковкиawaiting_packaging✅ включён
Ожидает отгрузкиawaiting_deliver✅ включён
Передано в доставкуdelivering☐
Доставленоdelivered☐
Отмененоcancelled☐
Не принятоnot_accepted☐

Кнопки «✓ Выбрать все» и «□ Снять все».

Отмеченные здесь статусы определяют, какие заказы вообще попадут в 1С. Если заказ есть на площадке, но не появился в модуле — первым делом проверьте этот список.

Для полного отслеживания жизненного цикла (включая отмены и доставки) отметьте все статусы. Для минимальной нагрузки оставьте только два первых.

Параметры создания документов 1С

ПолеНазначение
Префикс номераПрефикс, добавляемый к номеру создаваемого документа
Авто-проведение при созданииПроводить документ сразу. Включено по умолчанию

Нажмите «Сохранить».

Рабочий стол → строка «Отгрузка» → ⚙ Настройка.

БлокПараметрНазначение

Контроль отгрузки (FBS-сканер)Проверять отгрузку FBS сканеромТребовать сканирование при сборке. Включено по умолчанию
Формат штрихкода грузового местаАвто или конкретный формат
Ордерная схемаНа складе включена ордерная схемаОтметьте, если склад работает по ордерной схеме. Доступно в УТ 11

Нажмите «Сохранить».

Часть кнопок недоступна, если механика не подключена к проекту или неприменима к площадке. Например «Указать ГТД» и «Марки (КИЗ)» активны только при включённых соответствующих механиках, а «Поставка WB» — только для Wildberries.

Шаг 5. Смена статуса и отгрузка

Блок «Смена статуса (выберите заказы → статус → отправьте)»:

  1. Выделите один или несколько заказов в таблице.
  2. Выберите Целевой статус — например Отгружен.
  3. Нажмите «💾 Сохранить и отправить».

Модуль создаёт документ отгрузки в 1С и сообщает площадке о смене статуса.

Кнопка «🔄 Синхр. отгрузки» подтягивает информацию об отгрузках. Если отгрузок нет, появится сообщение вида «Синхронизация выполнена (новых отгрузок нет / заказ не найден)» — это не ошибка, а штатный результат.

Как это работает

  1. По расписанию (частота опроса с Шага 3Г мастера, по умолчанию 15 минут) модуль запрашивает заказы в отмеченных статусах.
  2. По каждому новому заказу создаётся документ в 1С; при включённом авто-проведении — сразу проводится.
  3. Если подключены маркировка и ГТД, они отрабатывают в этот же момент.
  4. При смене статуса на «Отгружен» создаётся документ отгрузки и площадка получает уведомление.

Частые проблемы

СимптомРешение
Заказы не приходят1) Статус проекта Активен. 2) В настройке заказов отмечены нужные статусы. 3) «▶ Запустить цикл сейчас» на рабочем столе, затем «📥 Получить заказы»
Заказ есть на площадке, но не в 1СЕго статус не отмечен в настройке. Отметьте и нажмите «📥 Получить заказы»
Заказ пришёл, но документ 1С не созданПроверьте реквизиты Шага 4 мастера: контрагент, склад, договор. В КА 2 / ERP — обязательна организация
Документ создан, но не проведёнСнят флажок «Авто-проведение при создании». Либо проведению мешают учётные ограничения базы — проведите вручную
Колонка ГТД показывает ⚠ требуетсяЗаказ требует таможенных данных. Выделите его → «Указать ГТД». См. ГТД
Кнопки «Этикетка» / «Марки (КИЗ)» неактивныСоответствующая механика не подключена. Рабочий стол → «Механики (Шаг 3В)»
«Синхр. отгрузки» пишет «новых отгрузок нет»Штатное сообщение — отгрузок по заказу пока не было
Таблица не обновляется при возврате на вкладкуНажмите «↺ Обновить заказы» — формы 1С не перечитывают данные автоматически
