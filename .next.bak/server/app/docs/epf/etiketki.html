Как настроить печать этикеток

Механика печатает этикетки заказов FBS и грузовых мест FBM. Работает по кнопке — расписания у неё нет.

Доступна для маркетплейсов, сайтов и служб доставки.

Шаг 1. Включить механику

Шаг 3В мастера → отметить «Печать этикеток FBS/FBM».

В существующем проекте: рабочий стол → «Механики (Шаг 3В)» → отметить → пройти мастер до конца.

Шаг 2. Настроить принтер

Рабочий стол проекта → строка «Этикетки» → ⚙ Настройка.

Поле / кнопкаНазначение
Принтер для этикетокПринтер, на который отправляется печать
Автоматическая печать при переходе заказа в статус «Упаковать»Печатать этикетку автоматически при смене статуса
Тестовая печать 🖨Проверить принтер до боевой работы
СохранитьСохранить настройку

Рекомендуемый порядок: выбрать принтер → «Тестовая печать» → убедиться, что этикетка вышла корректно → «Сохранить».

Шаг 3. Напечатать этикетку заказа

Рабочий стол → «Заказы» → ▶ Рабочее место → выделить заказ → «🏷 Этикетка».

Кнопка активна только при подключённой механике этикеток.

Автоматическая печать

Если включён флажок «Автоматическая печать при переходе заказа в статус "Упаковать"», этикетка печатается сама, как только заказ переходит в этот статус. Ручное нажатие не требуется.

Это удобно при потоковой сборке FBS: заказы приходят, статус меняется, этикетки выходят на принтер.

Этикетки грузовых мест FBM

При работе по схеме FBO/FBM этикетки печатаются на грузовые места (короба, паллеты) из рабочего места поставок — см. FBM/FBO поставки.

Частые проблемы

СимптомРешение
Кнопка «🏷 Этикетка» неактивнаМеханика этикеток не подключена к проекту, либо не выделен заказ в таблице
Тестовая печать не проходитПроверьте, что принтер доступен с того компьютера или сервера, где выполняется 1С
Этикетка печатается некорректноПроверьте, что выбран именно этикеточный принтер, а не офисный
Автопечать не срабатываетПроверьте флажок в настройке и то, что заказ действительно переходит в статус «Упаковать»
Нужно напечатать повторноВыделите заказ и нажмите «🏷 Этикетка» ещё раз
