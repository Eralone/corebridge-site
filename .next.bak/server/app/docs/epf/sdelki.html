Как настроить синхронизацию сделок CRM

Механика переносит сделки CRM в 1С: по каждой сделке создаётся документ заказа. Опрос идёт по расписанию.

Шаг 1. Настроить

Рабочий стол проекта → строка «Сделки CRM» → ⚙ Настройка.

Здесь задаётся, какие сделки забирать и какой документ по ним создавать. Проверьте соединение кнопкой на форме и нажмите «Сохранить».

Шаг 2. Рабочее место «Сделки CRM»

Рабочий стол → строка «Сделки CRM» → ▶ Рабочее место.

Верхняя панель

ЭлементНазначение
ИнтеграцияID проекта (например CRM_001)
Статус циклаРезультат последнего обмена, например HTTP 200 · принято 4 · приземлено 4
Следующий опросВремя следующего запуска по расписанию
🔄 Синхронизировать сейчасЗапустить обмен немедленно
📋 Открыть детальКарточка выбранной сделки
✉ Повторить ACKПовторно подтвердить обработку события
ПоказатьФильтр (all и др.)
ПериодФильтр по дате (today и др.)
↺ Обновить таблицуПеречитать таблицу

Строка «Статус цикла» — главный индикатор. принято N · приземлено N означает, что все полученные события успешно превратились в документы. Если «приземлено» меньше «принято» — часть сделок не обработалась, смотрите колонку «Статус синхр.».

Итоги внизу: Итого, Успешно, Ожидают, Ошибки.

Кнопка «Настройка сделок» открывает форму настройки.

Какие документы создаются

КонфигурацияДокумент по сделке
УТ 11Заказ клиента
УНФЗаказ клиента
КА 2 / ERPЗаказ клиента (организация обязательна, партнёр берётся из контрагента)
БП 3.0⚠️ Счёт на оплату — заказа клиента в БП нет

Частые проблемы

СимптомРешение
Таблица пустаяНажмите «🔄 Синхронизировать сейчас», затем «↺ Обновить таблицу». Проверьте фильтр «Период» — по умолчанию today
«принято N · приземлено 0»События приходят, но документы не создаются. Проверьте реквизиты Шага 4 мастера: контрагент, склад, договор; в КА 2 / ERP — организацию
В колонке «Статус синхр.» ошибкаОткройте «📋 Открыть деталь» — там текст ошибки по конкретной сделке
Документ создан не на того контрагентаНастройте поиск дублей и контрагента по умолчанию в Контрагентах
Событие обработано, но CRM его повторяетНажмите «✉ Повторить ACK» — подтверждение обработки не дошло до сервера
Обмен идёт слишком редкоУменьшите интервал в настройке
