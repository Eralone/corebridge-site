С чего начать

  1. Получите JWT-токен и файл модуля. Токен лежит в кабинете на странице «Файл .epf» — путь до него показан пошагово со скриншотами.
  2. Установите модуль — выберите инструкцию под свою конфигурацию 1С в разделе «Установка» ниже.
  3. Пройдите мастер подключения — это общий сценарий для всех интеграций, все 5 шагов.
  4. Откройте инструкцию под свою задачу — маркетплейсы, сайты, CRM, сервисы.

О скриншотах

Все изображения — реальные экраны модуля в веб-клиенте 1С, снятые при автоматизированном тестировании сборки на демонстрационной базе 1С:Управление торговлей 11.

В других конфигурациях расположение элементов такое же; отличаются только состав полей и доступность отдельных механик — это отмечено в разделах «Различия по конфигурациям 1С» каждой инструкции.
