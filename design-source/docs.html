Установка .epf в 1С

За 5 минут вы получите рабочую интеграцию 1С с выбранным сервисом. Ниже - пошаговое руководство для всех поддерживаемых конфигураций: УТ 11.5, УНФ 3.0, Бухгалтерия 3.0, Комплексная автоматизация и ERP 2.5.

💡 Совет Если у вас несколько конфигураций 1С - установите .epf в каждую отдельно. Они не мешают друг другу и умеют обмениваться данными через общий API-ключ CoreBridge.

Требования

  • 1С:Предприятие 8.3.18 или выше (рекомендуется 8.3.22+)
  • Доступ в интернет с сервера 1С (HTTPS, исходящие порты 443 и 80)
  • Учётная запись пользователя 1С с правом на работу с внешними обработками
  • Аккаунт CoreBridge с действующим тарифом или пробным периодом

Шаг 1. Скачать .epf

В личном кабинете перейдите в раздел EPF модули и скачайте файл для вашей конфигурации:

unified_ut11.epf v3.0.4
Для Управления торговлей 11.5 · 842 КБ

Шаг 2. Загрузить в 1С

  1. Откройте 1С под пользователем с правами администратора.
  2. Перейдите в меню Файл → Открыть… и выберите скачанный .epf-файл.
  3. В открывшемся окне нажмите «Установить в справочник обработок» - это позволит запускать интеграцию прямо из интерфейса 1С, без ручного открытия файла.
  4. Подтвердите установку в меню Администрирование → Печатные формы, отчёты и обработки → Дополнительные обработки.

Шаг 3. Активировать API-ключом

После загрузки обработка предложит ввести API-ключ. Получить ключ можно в личном кабинете: Настройки → API → Создать ключ.

// Пример ключа (32 символа)
key: "cb_live_8f3a91c2d5e74b0f9a1c6b8d2e4f7a93"
env: "production"
workspace: "retail-m"
⚠️ Важно Не делитесь API-ключом с третьими лицами и не храните его в открытых репозиториях. Ключ даёт полный доступ к вашим интеграциям. Если ключ скомпрометирован - отзовите его в «Настройки → API» и создайте новый.

Шаг 4. Тестовая синхронизация

После активации запустите тестовую синхронизацию, нажав в обработке кнопку «Проверить соединение». В течение ~3 секунд CoreBridge вернёт статус:

{
  "status": "ok",
  "version": "3.0.4",
  "config": "УТ 11.5",
  "operations_left": 149 821,
  "integrations_ready": 8
}

Если всё ок - можно переходить к настройке первой интеграции. Инструкция для популярных сценариев:

O
Подключить Ozon примерно за 30 минут
FBO, FBS, etiquettes, маркировка
WB
Подключить Wildberries
Заказы, остатки, финансовые отчёты
Б24
Подключить Битрикс24
OAuth, воронки, двусторонняя синхронизация

API Reference (preview)

Все возможности интерфейса доступны через REST API. Базовый URL:

GET https://api.corebridge.ru/v1/{resource}
МетодEndpointОписание
GET/integrationsСписок интеграций
POST/integrationsСоздать интеграцию
GET/integrations/{id}/eventsСобытия интеграции
POST/workflows/{id}/runЗапустить воркфлоу вручную
GET/usageПотребление в текущем периоде
